План 30 low-risk изменений HeroCraft24
=======================================
Дата: 2026-08-08
База: 01_architecture_report.txt + 02_model_audit.txt + 03_ui_render_audit.txt +
      04_assets_audit.txt + 05_duplicate_map.txt

Принцип отбора:
- Не ломаем соседние слои (UI, data, assets).
- Каждый шаг — компактный, проверяемый, обратимый.
- Масштабные архитектурные вещи (AbstractFilteredViewModel, общий базовый
  фрагмент и т.п.) отложены.

D) Проверка после каждого шага
--------------------------------

После каждого этапа:
1. ./gradlew :app:assembleDebug (или build в Android Studio)
2. Запуск на устройстве/эмуляторе:
   - Equipment list → detail (проверить addSection/addRow/addText)
   - Spell list → detail (проверить школы, damage-секцию)
   - Reference → Class (Warlock/Artificer/Fighter) → subclasses/invocations/schems/maneuvers
   - Reference → Monster (проверить localizeCondition/Environment)
   - Reference → Background/Species/Item/Condition
   - Favorites toggle в equipment/spells
3. Проверка JSON-миграций:
   - python/jsonlint валидация (или просто build)
   - resolveReference("phb2024:<id>") для изменённых id
4. Локализация:
   - переключить AppLocale.current = "en", проверить что строки меняются корректно

Минимальный набор smoke-тестов:
- Открыть Artificer → убедиться, что schems отображаются
- Открыть Warlock → invocations раскрываются и закрываются
- Открыть Fighter → maneuvers отображаются
- Открыть fireball через Reference и через Spells → информация о damage одинаковая
- Открыть guard (monster) → не открывается background guard после #12
- Открыть piercer (feat) → не открывается monster piercer после #12


E) Что отложить
----------------

1. AbstractFilteredViewModel / базовый filtered-list фрагмент — слишком большое
   архитектурное изменение, требует переписывания трёх фрагментов.
2. Объединение ClassTable и Table — требует миграции 13 JSON-файлов.
3. Замена GameClass.invocations/metamagics/... на feature_blocks — требует
   миграции 13 class JSON и переписывания ReferenceDetailFragment.
4. String → enum в сериализации — требует сканирования 2771 JSON-файла.
5. Структурирование casting_time/duration — требует переработки 412 spell JSON.
6. Перенос renderClass/Monster в отдельные renderers — масштабный UI-рефакторинг,
   лучше делать после стабилизации текущего плана.
7. Замена SpellDetailFragment.buildLinkedTextView на ItemLinkifier (#30) —
   включён, но как отдельный финальный шаг с ручным тестированием.
