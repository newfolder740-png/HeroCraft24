    Реализации (все в ReferenceDetailFragment.kt):

    | Метод                    | Строка | open-ids set       | subtitle | table | desc2 |
    |--------------------------|--------|--------------------|----------|-------|-------|
    | createFeatureCard        | ~1120  | openFeatureIds     | level    | ✓     | ✓     |
    | createInvocationCard     | ~730   | openInvocationIds  | level+req| ✓     | ✓     |
    | createMetamagicCard      | ~530   | openMetamagicIds   | cost     | ✗     | ✗     |
    | createManeuversCard      | ~560   | openManeuversIds   | ✗        | ✗     | ✗     |
    | createSchemsCard         | ~590   | openSchemsIds      | ✗        | ✓     | ✓     |
    | createSpeciesTraitCard   | ~1310  | (нет!)             | level    | ✓     | ✓     |
    | createClassSubclassCard  | ~410   | (нет!)             | ✗        | ✓     | ✓     |

    Общий boilerplate (повторяется 7 раз, ~30 строк каждая):
    1. MaterialCardView(context).apply { layoutParams, radius=12dp, cardElevation=2dp }
    2. LinearLayout(context).apply { orientation=VERTICAL, padding=16dp }
    3. card.addView(inner)
    4. TextView(context).apply { text=title, TitleMedium, BOLD }
    5. inner.addView(title)
    6. LinearLayout(context).apply { orientation=VERTICAL, isVisible=false }
    7. inner.addView(body)
    8. body.addView(buildRichLinkedTextView(description))
    9. (опционально) body.addView(createTableView(table))
    10. (опционально) body.addView(buildRichLinkedTextView(desc2))
    11. if (id in openXxxIds) body.isVisible = true
    12. card.setOnClickListener { body.isVisible = !body.isVisible; update openXxxIds }

    Что меняется:
    - title-формат: "Уровень ${level}: ${name}" (Feature, SpeciesTrait) vs "${name}" (остальные)
    - subtitle-формат: "уровень Колдуна $it" (Invocation) vs "${name} • $cost" (Metamagic) vs нет
    - body-контент: buildRichLinkedTextView всегда, table/desc2 опциональны
    - open-ids set: 5 имеют, 2 не имеют (SpeciesTrait, Subclass)
    - FeatureCard имеет ленивый linkify (placeholder → linked при первом раскрытии)
