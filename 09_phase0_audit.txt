A) Проверка поддержки английского UI
-------------------------------------
1. Ресурсы `values-en` не найдены. Поиск по проекту `**/values-en/**` дал 0 результатов.
2. Единственный `strings.xml` в `feature/reference/src/main/res/values/strings.xml`
   содержит строки только на русском (`size_*`, `type_*`, `skill_*` и др.).
3. `AppLocale` (`core/model/AppLocale.kt`) — изменяемая глобальная переменная,
   которая используется только в `LocalizedString.get()` для выбора `en`/`ru`
   значения из JSON-контента. Для Android UI-строк она не применяется.
4. `UiLocalizer` реализован как context-free `object` в модуле `core:ui`.
   Использование `R.string` потребовало бы:
   - передавать `Context` во все методы локализатора;
   - добавлять зависимость `core:ui` от строк `feature:reference`,
     что нарушает модульную границу.
5. Решение: оставлены hardcoded русские строки в `UiLocalizer.size/type/skill`.
   Добавлен поясняющий комментарий в `UiLocalizer.kt` с обоснованием
   (русскоязычный UI, отсутствие `values-en`, context-free объект).

C) Проверка персистентности FavoritesStore
--------------------------------------------
1. `FavoritesStore` (`core/ui/.../data/FavoritesStore.kt`):
   - `load()` читает `SharedPreferences.getStringSet("ids", emptySet())`;
   - `save()` пишет через `putStringSet(...).apply()`;
   - `toggle()` изменяет копию множества и сразу сохраняет её.
2. Имена SharedPreferences сохранены:
   - `EquipmentViewModel` использует `equip_favs`;
   - `SpellsViewModel` использует `spells_favs`.
   Переименования не производилось, миграция данных не требуется.
3. В `core/ui/src/test/java/.../data/FavoritesStorePersistenceTest.kt` добавлены тесты:
   - пустое хранилище возвращает empty set;
   - toggle добавляет и удаляет id;
   - новый экземпляр `FavoritesStore` видит ранее сохранённый набор
     (имитация "перезапуска" через новый Context);
   - toggle возвращает обновлённый набор и сохраняет его.
4. Результат: `./gradlew :core:ui:test` — 4/4 теста FavoritesStore прошли.
5. Ограничение: реальный перезапуск приложения с проверкой сохранности избранного
   требует эмулятора/устройства; в рамках JVM-тестов проверена корректность
   persistence-контракта класса.

D) Риски и что оставить как есть
---------------------------------
1. Без английских `values-en` hardcoded русские строки в `UiLocalizer`
   не являются регрессией. Если в будущем планируется EN-локаль, нужно будет
   добавить `values-en/strings.xml` и передавать `Context` в `UiLocalizer`.
2. `ItemLinkifier` с stem-matching даёт более широкую линковку, чем ручной
   `indexOf`. Это ожидаемо, но на реальном устройстве стоит проверить
   отсутствие ложных ссылок (например, в словах "очарование", "очаровывали").
3. `FavoritesStore` не шифрует SharedPreferences — в рамках текущего плана
   это ожидаемо.
4. Добавленные тесты полагаются на `org.mockito:mockito-core` и JUnit 4.
   Это увеличивает зависимости модуля `core:ui`, но только для `test` scope.

F) Срочный hotfix после аудита (NPE в ReferenceViewModel)
---------------------------------------------------------
1. Симптом: crash `NullPointerException: Attempt to do a synchronize operation on a null object`
   в `ReferenceViewModel.getCombinedNameMap` (ReferenceViewModel.kt:145).
2. Причина: `private val lock = Any()` был объявлен ПОСЛЕ `init { preloadClasses() }`.
   `preloadClasses()` запускает корутину, которая сразу вызывает `synchronized(lock)`,
   но в момент запуска корутины `lock` ещё не инициализирован.
3. Исправление: переместить `private val lock = Any()` до `init` блока.
   Добавлен комментарий о причине.
4. Проверка: `./gradlew :feature:reference:compileDebugKotlin` — BUILD SUCCESSFUL.
